# Preparação para produção — plataforma empresarial multiagente

**NO-GO para produção; continuar a qualificação com componentes prontos.** Foram investigados cérebro/integridade/ACL, temporalidade, identidade, sandbox, custos, PostgreSQL, recuperação e operação por cliente, com empresa grande como referência e testes locais menores.

Leia o [parecer principal](REPORT.md). Detalhes: [cérebro](BRAIN.md), [segurança](SECURITY.md), [custos](COSTS.md), [operação](OPERATIONS.md), [gates](GATES.csv), [comandos](COMMANDS.md), [fontes](SOURCES.md) e [trace de código](SOURCE_TRACE.md).

62 testes LightRAG, 3 provas de cérebro, 16 testes Graphiti e 8 testes de contabilização passaram; também houve provas separadas de identidade, sandbox e PostgreSQL. Esses números não equivalem a homologação da plataforma inteira. Artefatos sintéticos e falhas preservadas em evidence/. Nenhuma chamada paga de modelo foi executada.
