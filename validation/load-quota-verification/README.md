# Regressão complementar de quota — zero modelos

Backend copiado byte a byte do ensaio load-and-capacity; apenas prefixo de recursos e teste específicos. A comparação de hashes está no consolidador principal. Executa APIs/PG/Neo4j/Keycloak/autoridade reais; nenhuma extração, embedding de documento ou inferência CLI é chamada.

A API gera uma abstenção legítima para data anterior à vigência da nota e persiste o registro. Uma intenção é interrompida e encerrada por duas identidades; a quota é preenchida com 40 reservas locais sem CLI. Exige 429 para uma pergunta nova, 409 para o fingerprint encerrado, nenhuma admission/seq adicional e 16 leituras exatas de histórico nas duas APIs. Um teste passou em 111,55 s. É prova de infraestrutura da recusa pré-admissão, não novo benchmark de corpus/semântica/performance ou repetição do E2E principal.

Segredos e .state ficam fora do pacote de entrega. O relatório e decisão consolidados estão no diretório load-and-capacity.
